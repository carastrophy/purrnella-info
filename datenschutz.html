Datenschutz

Purrnella ist eine private App für einen einzelnen Haushalt. Nur die Mitglieder dieses Haushalts nutzen sie.

Google-Kalender

Purrnella greift über die Google Calendar API auf den Kalender des eigenen Haushalts zu. Sie liest Termine, um sie anzuzeigen, und legt Termine an, wenn jemand aus dem Haushalt das tut.

Wo die Daten liegen

Die Daten bleiben auf dem eigenen Server des Haushalts. Sie werden nicht verkauft, nicht ausgewertet und nicht an Dritte weitergegeben. Es gibt keine Werbung und kein Tracking.

Zugriff entziehen

Der Zugriff lässt sich jederzeit unter myaccount.google.com/permissions widerrufen.
